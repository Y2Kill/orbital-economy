# Цены в затраты — прототип на v7.7.15 (полный денежный учёт, шаг 1)

Дата: 2026-10-16. База — принятая v7.7.15 r1. Исследование, не задача.

Повод: первый прототип бюджетов домохозяйств (`FINANCE_PROTOTYPE_2026-10-12_RU.md`) показал, что денежный круг модели не замкнут. Цены руды, энергии и еды ниже трудозатрат, и выплаченные зарплаты не возвращаются через цены.

Скрипты лежат в `ARCHIVE/evidence/041-cost-prices/`:
- `cost_prices.mjs` — анализ затратных цен;
- `cost_price_prototype.mjs` — прототип.

## 1. Анализ: какими были бы цены по затратам

Полная стоимость единицы складывается из:
- материалов и энергии по ценам региона;
- труда × автоматизация × зарплата;
- износа капитала: оборудование и стройматериалы на единицу мощности × износ, по их затратной цене;
- постоянных затрат на единицу при нынешней загрузке;
- прежней «базовой» цены как ренты.

Цена = стоимость × (1 + наценка). Решено как неподвижная точка (цены Леонтьева) при средних первого года Mode 52.

| Товар | A: сейчас → по затратам | B: сейчас → по затратам | Доля труда в затратах A |
|---|---|---|---|
| энергоресурс | 0.04 → 0.26 (×6.6) | 0.04 → 0.35 (×8.7) | 76 % |
| энергия | 0.12 → 0.45 (×3.7) | 0.07 → 0.53 (×7.5) | 22 % |
| руда | 4.0 → 9.5 (×2.4) | 14.0 → 21.5 (×1.5) | 53 % |
| металл | 25.9 → 48.4 (×1.9) | 34.5 → 77.4 (×2.2) | 24 % |
| электроника | 23.1 → 27.0 (×1.2) | 21.9 → 39.2 (×1.8) | 22 % |
| еда | 10.4 → 15.2 (×1.5) | 10.0 → 21.2 (×2.1) | 98 % |
| оборудование | нет цены → 284 | → 403 | 70 % |
| стройматериалы | нет цены → 84 | → 114 | 36 % |
| реголит | нет цены → 24.5 | → 33.3 | 81 % |

Главная причина — энергия. Добыча энергоресурса требует 0.002 труда на единицу, то есть 0.2 при зарплате 100, а энергоресурс стоит 0.04. На тонну металла идёт 30 единиц энергии, поэтому энергия в металле — 13.5 вместо 3.6. При затратных ценах потребительская корзина A стоит 1739 в день, больше фонда зарплат (1456). Разницу дают рента и наценки — их надо будет вернуть домохозяйствам как доход.

## 2. Решения владельца (2026-10-16)

- **цены поднимаются до затрат, зарплаты не меняются;**
- **рента — сверх затрат:** прежние базовые цены руды, генерации и энергоресурса остаются платой за природный ресурс;
- **наценка 15 % для всех товаров** (прежде только металл 15 % и электроника 18 %).

## 3. Прототип

Переключатель `Cost Pricing Enabled`; при 0 формулы v7.7.15 сохраняются точно.

- **Цены руды, энергоресурса, энергии и еды** = полная стоимость × 1.15 × прежний множитель дефицита.
- **Себестоимость металла и электроники** получает износ капитала; наценка электроники — 15 %.
- **Новые затратные цены** у оборудования, стройматериалов и реголита. Пока они служат только для оценки износа капитала.
- **Сглаженные сигналы цен** (10 дней) читаются формулами затрат. Без них энергия, энергоресурс и руда образуют алгебраические петли: энергия нужна для добычи энергоресурса, а энергоресурс — для энергии.
- **Постоянные затраты на мощность в цену не входят** и по-прежнему вычитаются из прибыли: цена, зависящая от текущего выпуска, дала бы ещё одну петлю. У металла это около 4.7 из 48.
- **Опорные цены** спроса и индекса цен умножены на «стартовая затратная цена / стартовая цена», по региону, через именованные параметры. На старте спрос и реальная зарплата не прыгают. Для еды индекс получает региональную опорную цену: затраты регионов на еду различаются (A 17.6, B 24.5).

Новые Modes:
- **56** — Mode 52 с затратными ценами;
- **57** — Mode 53 (всплеск) с ними.

Модуль `wage_pricing` в них выключен: труд и так входит в цены полностью.

## 4. Результат

| Год 80 | Mode 52 | Mode 56 (затратные цены) |
|---|---|---|
| металл A / B | 26 / 34 (цена) · выпуск 36.7 / 2.3 | 58 / 64 (цена) · выпуск 30.2 / **8.6** |
| электроника A, выпуск | 26.1 | 19.1 |
| энергия A, цена | 0.12 | 0.56 |
| еда A / B, цена | 10.7 / 10.0 | 17.8 / 15.0 (B: 23.3 на 5-й год) |
| индекс цен A / B | 0.83 / 0.86 | 0.83 / **0.70** |
| зарплата A / B | 91 / 95 | 97 / 85 |
| реальная зарплата A / B | 109 / 111 | **116 / 122** |
| население A / B | 32.6 / 10.2 | 27.2 / **15.6** |
| вывоз еды B → A | 12.6 | 7.2 |
| напряжённость рынка труда B | 0.92 | 0.91 |
| прибыль переработки A | 94 | 311 |

**Выводы:**

1. **Модель устойчива** при ценовом уровне примерно ×2.2; петель нет.
2. **Затратные цены делают то же, что `wage_pricing`, но сильнее.** Труд входит в цены всех товаров полностью, поэтому падение зарплаты B удешевляет всё, что производит B. B выплавляет 8.6 вместо 2.3, её население растёт до 15.6. A теряет часть выпуска и населения. Реальные зарплаты растут в обоих регионах, у A перестают падать.
3. **Дрейф зарплаты B не устранён, но меняет смысл.** Номинальная зарплата B падает до 85, а реальная растёт, потому что цены B падают вместе с ней.
4. **Прибыль выросла втрое–впятеро:** 15 % теперь берутся с вдвое большей себестоимости. Это доход, который на следующем шаге надо платить домохозяйствам. Вместе с рентой он и замыкает денежный круг.
5. **Калибровка опорных цен на старте неточная.** Индекс цен A на 3-й год 0.87 против 0.83 в Mode 52, реальная зарплата A −4 %. Для шага модели стоит считать масштаб по стартовым значениям самих Modes, а не по оценке неподвижной точки.

## 5. Что дальше (предложение)

1. **Шаг модели под переключателем.** Затратные цены — новым узлом `cost_pricing` поверх всех: он заменяет формулы узла `food` (цена еды, индекс цен). Сначала задача стенду, затем модели, как для `wage_pricing`. Modes 0–55 не меняются; новые Modes 56–57. `wage_pricing` при включённых затратных ценах выключен.
2. **Затем — денежные запасы домохозяйств и фирм.** Доход = зарплата + распределённая прибыль + рента. Каждый платёж — с двух сторон, межрегиональный платёжный баланс.
3. **Позже, когда денежный учёт сойдётся,** перевести модель на затратные цены целиком. Это будет перекалибровка всех Modes, как v7.7.14.

База: accepted **v7.7.18 r1** — затратные цены во всех Modes, деньги в полных. Сервер (Linux, не каноническая платформа), счёт годовыми кусками с переносом запасов: отличие от сплошного прогона около 1e-11, только для исследования.

Скрипты и сырой отчёт — `ARCHIVE/evidence/049-longrun-v7718/`:
- `lr.mjs`, `sw.mjs`;
- `run.sh`, `supervise.sh`;
- `analyze.py`, `report.txt`.

Устойчивость к сбоям питания:
- долгий прогон сохраняет состояние после каждого модельного года;
- анализ чувствительности дописывает каждый прогон строкой;
- надзор сам перезапускает работу после перезагрузки.

Проверено на деле: сбой застал прогоны на 8-м году, перезапуск продолжил с него. Нечисловых значений и ошибок — 0.

## 1. Три мира, 80 лет

Сравниваются:
- **base52** — полная экономика: затратные цены + деньги;
- **nomoney56** — затратные цены без денег;
- **oldprices52** — прежние цены, без денег.

| Показатель (среднее за год) | base52: год 1 → 20 → 80 | nomoney56: год 80 | oldprices52: год 80 |
|---|---|---|---|
| население A / B | 27.9 / 8.6 → 28.4 / 9.6 → 29.3 / **13.5** | 28.4 / 14.4 | 32.6 / 10.2 |
| металл B | 2.1 → 2.2 → **5.1** | 7.1 | 2.3 |
| электроника B | 12.5 → 7.7 → **13.7** | 15.2 | 8.5 |
| зарплата A / B | 100 / 140 → 98 / 107 → **85 / 79** | 96 / 88 | 91 / 95 |
| реальная зарплата A / B | 120 / 160 → 119 / 139 → 116 / 121 | 118 / 123 | 109 / 111 |
| индекс цен A / B | 0.83 / 0.88 → 0.83 / 0.77 → **0.73 / 0.65** | 0.81 / 0.72 | 0.83 / 0.86 |
| деньги домохозяйств A / B | 169 тыс. / 52 тыс. → 162 тыс. / 61 тыс. | — | — |
| доля бюджета A / B | 0.97 / 0.98 → 0.96 / 0.79 | — | — |
| платёжный баланс A / B, в день | −151 / +86 → −34 / −33 | +65 / −132 | −4 / −72 |
| энергия, еда | обеспечены весь срок | обеспечены | обеспечены |

**Выводы:**

1. **Полная экономика устойчива 80 лет.**
   - Деньги у цели, долгов нет.
   - Дефицит B закрыт: −33 в день — это остаток фрахта, который транспорт возвращает домохозяйствам.
   - Без денег дефицит B хронический (−132), с прежними ценами тоже (−72).
2. **B оживает только на затратных ценах.**
   - Население B 13.5–14.4 против 10.2 на прежних ценах.
   - Металл B 5–7 против 2.3.
   - На прежних ценах B остаётся маленьким: его зарплата 140 не возвращается через цены, а на затратных возвращается.
3. **Главная находка — номинальная дефляция без дна.**
   - Зарплаты падают весь срок: A 100 → 85, B 140 → 79. К 80-му году падение ещё идёт — 2–3 % за десятилетие.
   - Цены идут за зарплатами через трудовые затраты: индекс B 0.88 → 0.65.
   - Реальная зарплата падает медленнее: A 120 → 116.

   Это известная структурная особенность из v7.7.14: зарплата дрейфует, пока напряжённость рынка труда не равна цели 0.95, и не влияет на спрос на труд. На прежних ценах дрейф был слабее (A → 91), затратные цены его усиливают: зарплата → затраты → цены → индекс. Номинальная шкала модели не закреплена. Это кандидат на модельное решение: якорь зарплаты, связь «зарплата → спрос на труд» или цель по ценам.
4. **Равновесие B не достигнуто и за 80 лет:** население, металл и транспорт B растут на 3–5 % за десятилетие.

## 3. Чувствительность: ±20 %, 66 параметров, Mode 52, 20 лет

Метод:
- значения параметров взяты из v7.7.18;
- в прошлом списке их значения устарели, например запас генерации стоял 1.02;
- добавлены параметры затрат и денег.

Всего 133 прогона, ошибок 0.

**Итог:** 24 параметра сильные (|эластичность| ≥ 1), 26 средние (0.3–1), 6 инертных.

**Сильнее всего отзывается металл B.** Это малая величина (около 2 в год 20), поэтому относительные эластичности велики. Пороговые, односторонние параметры — −20 % резко меняет картину, +20 % почти ничего:
- `B Ore per Metal`: −5.1;
- `Labor Participation Share`: −4.9;
- `Refinery Operating Reserve Factor`: −4.3;
- `Power Resource Extraction Headroom`: −3.4;
- `Power Operating Reserve Factor` по цене металла A: −1.8.

**Параметры затрат и денег:**
- `Household Money Target Days` — сильный (−1.1 по металлу B, −0.66 по доле бюджета B), как и предсказывал прототип: он задаёт уровень активности;
- `Firm Money Target Days`, `Dividend Payout Time` — средние (около −0.5);
- `Universal Markup` — средний (−0.75 по металлу B, −0.25 по реальной зарплате A);
- масштабы опорных цен — средние (около 0.6–0.75);
- `Target Labor Tightness` — сильный по зарплате A (−1.4) и по цене металла A (−0.8): это рычаг дефляции из §1;
- инертны: `Transport Payout Time`, `Household Income Smoothing Time`, `Cost Price Signal Time`, `Base Power Resource Price`, `Power Resource Extraction Energy per Unit`, `Electronics Capacity Planning Adjustment Time`.

**Особенность калиброванного старта.** У `Firm Money Target Days`, `Dividend Payout Time`, `Household Money Target Days` металл B падает при **обоих** знаках отклонения. Старт денег — откалиброванная неподвижная точка, и любой сдвиг уводит от неё в переходный процесс. Это не дефект, но эластичности этих параметров отражают уход от равновесия, а не наклон.

## 4. Что предложить дальше

1. **Номинальный якорь** — главный вопрос модели после перехода на затратные цены. Варианты для решения владельца:
   - зарплата возвращается к норме, а не только реагирует на напряжённость;
   - связь «зарплата → спрос на труд»;
   - денежная цель по ценам.

   Нужен прототип на сервере с тем же надзором.
2. **Полностековые шоки как Modes validation** — после решения о якоре: иначе пороги придётся пересчитывать.
3. **Morris** на сильных параметрах из §3, если понадобится картина взаимодействий.

# Отчёт исполнителя — задача 006

## Среда и стратегия

Ветка создана от `main@7f130590d409321531f91525ee1ce0e48ba5c6ad`. Диагностика использует тот же `simulation@9.0.0` и Node 24.11.1.

Для экономии Windows-минут workflow сначала делает один полный digest-прогон выбранных Modes на Ubuntu и Windows, затем повторно симулирует только реально различающиеся Modes и сохраняет только ряды с различными digest. Последний job ищет первый различающийся шаг по точным IEEE-754 битам.

До первого cross-OS запуска `repro.mjs` — bootstrap-заглушка. После определения первой расходящейся операции она будет заменена минимальным самостоятельным воспроизведением.

SUMS не изменяются (`sums_by: reviewer`). Модель, validation, policy, vendor и существующие workflow не изменяются.

# v7.7.15 — зарплата в ценах (финансовый слой, промежуточный шаг) — спецификация

Статус: **r1** (2026-10-16). База: accepted **v7.7.14 r1** (SHA `bbb4f9ea…`). Стенд: **Lab v0.9.19** (задача 036).

## Основание

- **Дрейф зарплаты B** (анализ Morris, `docs/research/SENSITIVITY_2026-10-10_RU.md`, третий проход). Зарплата входит только в себестоимость металла и электроники. Когда в B мало работы, зарплата падает, но ничего в экономике от этого не меняется.
- **Первый прототип финансового слоя** (`docs/research/FINANCE_PROTOTYPE_2026-10-12_RU.md`). Бюджеты домохозяйств поверх нынешних цен дали депрессивную спираль: денежный круг модели не замкнут.

**Решения владельца (2026-10-12):**
- вариант 3: сейчас реальные величины и передача зарплаты в цены, затем полный денежный учёт поверх;
- состав шага: пропорциональная передача зарплаты в цены руды, энергии и еды; спрос от цены (η = 0.5); спрос от дохода не вводится.

## 1. Что меняется

1. **Узел `wage_pricing`** (декларация `draft/wage_pricing.json` = фикстура задачи 036) под переключателем `Wage Pricing Enabled`:
   - **цены руды, энергии и еды** каждого региона × `Max(1 + доля труда × (зарплата / стартовая − 1), 1e-6)`. Доли труда:

     | | руда | энергия | еда |
     |---|---|---|---|
     | A | 1 | 0.83 | 1 |
     | B | 0.5 | 1 | 1 |

     Доля = стартовая стоимость труда / стартовая цена (средние первого года Mode 52 на v7.7.14), не больше 1. Почти везде она упирается в 1: ценовой уровень модели ниже трудозатрат (отчёт о прототипе, вывод 4);
   - **эффективный спрос на металл и электронику** × `Max(цена / опорная, 1e-6)^(−0.5)`. Опорные цены — средние первого года Mode 52: металл A 25.9, B 34.46; электроника A 23.1, B 21.91.
2. **Окно всплеска транспорта** открывается и в Mode 55: `Test 2 Transport Surge Active` получает внешнюю ветку `IfThenElse([Timed Test Mode] = 55, [Temporary Test Window], …)`, как задача 034 сделала для Mode 53.

Узел раскрывается в 18 элементов, 10 замен и 42 связи. Запасов и потоков нет. При `Wage Pricing Enabled = 0` ни один прежний ряд не меняется.

## 6. Поведение

**3 года (validation)** — эффект небольшой: зарплата за это время сдвигается на 3 %.

| | Mode 52 → 54 | Mode 53 → 55 |
|---|---|---|
| руда B, min | 14.00 → 13.77 | |
| еда B, max 3-го года | 10.01 → 9.82 | |
| энергия B, min | 0.0700 → 0.0677 | |
| доступность труда A, min | | 0.946 → 0.964 |
| цена металла A, max | | 36.5 → 33.4 |

**80 лет (исследование, сервер; Mode 54 прототипа узла, `ARCHIVE/evidence/039-wage-pricing/`):**
- металл B: 1.7 → 7.8;
- население A / B: 28.6 / 14.2 (база 32.6 / 10.2);
- реальные доходы на душу A / B: 58.6 / 60.0, почти сошлись;
- напряжённость рынка труда B: 0.92.

Главная цепочка идёт через еду: зарплата B падает → еда в B дешевле → реальный доход B держится → меньше уезжают → в B больше спроса и выпуска. Без передачи зарплаты в цену еды результат близок к базе.

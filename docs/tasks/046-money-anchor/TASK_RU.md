# Задание 046 — денежный якорь в узле `money`; эластичность спроса на труд может быть 0

Ветка: `task/046-money-anchor` · Scope: `scope.json` рядом · Правила: контракт 1.9 §9, §9.2 п. 9 (контрольные точки и журнал), §9.4 · Порядок работы: `docs/tasks/README_RU.md`

## 1. Зачем

**Что показали долгие прогоны v7.7.19** (`docs/research/LONGRUN_V7_7_19_2026-10-24_RU.md`). Якорь через спрос на труд держит номинал, но:
- множитель (Wage / Initial Wage)^(−1.5) раздувает наём и зарплатный фонд, а цены видят только технический труд;
- деньги фирм B уходят в минус около 97-го года.

**Что показали прототипы** (`docs/research/ANCHOR_BUDGET_2026-10-24_RU.md`, три раунда):
- честная цена труда закрывает утечку, но якорь через труд перестаёт работать (ни при ε = 1.5, ни при 1.0);
- рабочий якорь — **денежный**: выпуск денег домохозяйствам, пока общий индекс цен ниже цели;
- один якорь на общую валюту (MU5) держит номинал, занятость и доли бюджета, утечки и межрегионального насоса нет.

**Решение владельца (2026-10-25):** денежный якорь вместо якоря через труд. Путь тот же, что в 044 → 045: сначала стенд, потом модель.

**Что делает эта задача (стенд, Lab v0.9.24):**
1. Узел `money` получает **необязательный** блок `anchor`: общий индекс цен, выпуск денег в поток доходов домохозяйств и явный счёт выпуска `Money Issued Total`.
2. Плагин `money` проверяет сохранение «деньги − выпущено» вместо «деньги», если в плагине указан счёт выпуска.
3. `labor_market` принимает `Labor Demand Wage Elasticity` = 0: так модельная задача 047 выключит прежний якорь, не перестраивая слой.
4. `node_qa`: снятие и пересборка слоя с якорем.

Без блока `anchor` раскрытие `money` не меняется ни на байт. **Модель, validation и policy не меняются.** Первым применением станет модельная задача v7.7.20 (047).

- **где деньги выключены** (0, 23, 56, 57), выпуск 0, деньги постоянны.

### 1.2 Свойства, на которых стоит изменение

- **Выпуск идёт только в поток.** Он попадает в `{C} Household Income Flow`, а не в `{C} Household Income`. Поэтому тождество дохода, бюджеты и сглаженный доход прежние, меняется только остаток денег.
- **Без денег ничего не меняется.** Поток выпуска обёрнут тем же `IfThenElse([Money Enabled] = 1, …, 0)`, что и прочие денежные потоки. При выключенных деньгах выпуск и `Money Issued Total` равны 0, а ряды прежних элементов не меняются.
- **Эластичность 0 даёт прежние ряды.** При ε = 0 множитель `(W / W0) ^ (-0)` равен 1 точно (IEEE: `pow(x, -0) = 1` для любого x), умножение на 1 точно. Ряды всех прежних элементов равны рядам слоя без параметра бит в бит.

## 2. Денежный якорь

### 2.1 Декларация

Необязательный ключ верхнего уровня `anchor`, все поля обязательны:

```json
"anchor": { "price_index": "{C} Price Index", "weight": "{C} Population", "target": 0.8439, "time": 1800 }
```

- `price_index`, `weight` — шаблоны с `{C}`; элементы должны быть в базе.
- `target`, `time` — конечные числа > 0.
- Незнакомое поле, отсутствующее поле или неверный тип — ошибка с путём.

Фикстура — `fixtures/money_anchor.json`: `model/nodes/money.json` плюс блок выше.

### 2.2 Раскрытие

Если блок есть, порождаются (после всех прежних элементов, в этом порядке):

| Элемент | Тип | Значение |
|---|---|---|
| `Money Anchor Time` | VARIABLE | `time` |
| `Union Price Index Target` | VARIABLE | `target` |
| `Union Price Index` | VARIABLE | `(Σ [{C} weight] * [{C} price_index]) / Max(Σ [{C} weight], 0.000001)` |
| `Union Price Gap` | VARIABLE | `([Union Price Index Target] - [Union Price Index]) / [Union Price Index Target]` |
| `{C} Money Issue` | VARIABLE, на регион | `[{C} Household Money] * [Union Price Gap] / [Money Anchor Time]` |
| `Money Issued Total` | STOCK, 0, `non_negative: false` | — |
| `Money Issue Flow` | FLOW ∅ → `Money Issued Total` | `IfThenElse([Money Enabled] = 1, Σ [{C} Money Issue], 0)` |

Кроме того:
- `{C} Household Income Flow` получает значение `IfThenElse([Money Enabled] = 1, [{C} Household Income] + [{C} Money Issue], 0)`;
- имена, формулы, порядок, описания и связи — **как в прототипе**;
- без блока раскрытие прежнее.

**Фрагмент validation:**
- `money_issued: "Money Issued Total"`;
- `Money Issue Flow` добавляется в `money_boundary_flows`.

### 2.3 Слияние validation, плагин, conformance

- **`mergeNodeValidation`** (`lab/src/nodes/index.js`): при `money_issued` плагин `money` получает поле `issued`. Различие `issued` между фрагментами — ошибка, как различие `switch` или `transport`.
- **Схема плагина** (`validation_schema.js`, `validateMoneySpec`): `issued` необязательно; если есть — непустая строка.
- **Runtime** (`checks.js`, проверка `money: total money conserved`): при `issued` сохраняется «Σ денег домохозяйств и фирм + деньги перевозчика − `issued`»; без `issued` проверка прежняя.
- **Conformance** (`runMoneyConformance`): колонка `issued` проверяется на существование, как прочие.
- **Документация:** `lab/docs/VALIDATION_FORMAT_RU.md`, раздел плагина `money`.

### 2.4 Снятие слоя (`node_qa`)

- `moneyGeneratedNames` при наличии `anchor` включает имена якоря, в том числе `{C} Money Issue`.
- Снятие удаляет их со связями; `{C} Household Income Flow` порождается узлом и уходит вместе со слоем, как раньше.
- `validationWithoutMoneyFragment` снимает и `Money Issue Flow` из границ — уже так работает, проверить.
- Слой, принятый в модели с якорем, снимается и собирается по **своей декларации** из `model/nodes/` — правило случаев 44, 60 и 94.

## 3. `labor_market`: эластичность может быть 0

- Проверка параметра `Labor Demand Wage Elasticity`: конечное число **≥ 0**; отрицательное и нечисло — ошибка, как раньше.
- Раскрытие при 0 — то же, что при любом другом значении: параметр и замена `{C} Total Labor Requirement` есть, формула прежняя.
- Сообщение об ошибке: `must be a finite number >= 0`.

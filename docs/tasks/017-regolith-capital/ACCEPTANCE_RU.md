## Находки

**1. Validation r1: тождество выключенного режима в новых Modes (исправлено в r2).** Проверка «мощность добычи = прежняя константа» верна только при выключенном переключателе, а исполнитель распространил её и на Modes 38–39. Validation r1 падала честно: ошибка громкая, не тихая, как в 014. Это то же правило, что уже записано в истории проекта: парное тождество проверяется только там, где его ветка активна.

**2. Сжатая validation.** Исполнитель сжал validation (692 888 байт против 871 633 у v7.7.4), потому что guard считает файл больше 1 МБ бинарным. Сжатие не меняет содержания. Самотест узлов (случай 9) требует, чтобы `expand-nodes --validation` возвращал принятую validation побайтно. Это выполняется при любом форматировании: если слияние ничего не меняет, CLI копирует исходный файл. Поэтому **принятая v7.7.5 тоже хранится сжатой**. Лимит guard для текстового JSON — отдельная задача инструментов, не в этой ветке.

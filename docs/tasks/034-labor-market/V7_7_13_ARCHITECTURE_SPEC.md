## 1. Что меняется

1. **Узел `labor_market`** (`draft/labor_market.json`, `lab/docs/NODES_RU.md`) на регионы A и B:
   - **спрос по населению:** базовый спрос на металл и электронику = норма на душу (уровень A: 16/28 и 20/28) × население;
   - **гибкая зарплата:** запас, который следует за напряжённостью = спрос на труд / рабочая сила;
     - цель 0.95;
     - скорость 10 % в год;
     - нижняя граница — 30 % стартовой;
   - **ограничение выпуска трудом** (предохранитель): скорости всех процессов региона (добыча, плавка, электроника, оборудование, реголит, стройматериалы, энергоресурс, генерация, фермы) × доступность труда = min(1, рабочая сила / спрос на труд);
     - спрос на труд — потребность при неурезанном выпуске, сглаженный запас (10 дней).
2. **Проводка всплеска для Mode 53.** Формула `Test 2 Transport Surge Active` оборачивается снаружи: `IfThenElse([Timed Test Mode] = 53, [Temporary Test Window], <прежняя>)`.

## 5. Наблюдения (skeleton, 3 года)

| | Mode 49 (без рынка труда) | Mode 52 | Mode 53 (всплеск) |
|---|---|---|---|
| спрос B на металл | 22 | 4.9 → 5.2 | 4.9 → 5.4 |
| зарплата A / B | 100 / 140 | 101 / 136 | 101 / 138 |
| напряжённость A / B, 3-й год | 1.21–1.29 / 1.15–1.33 | 1.00 / 0.77–0.78 | 0.96–1.04 / 0.74–0.92 |
| доступность труда A, минимум | 1 | 0.997 | **0.961** |
| металл B, среднее | 8.9 | 1.7 | 2.3 |
| цена металла A, среднее | 37.2 | 26.7 | 29.4 |
| мощность транспорта, 3-й год | 23–26 | 11 | 10–15 |
| еда A / B | 1.00 / 1.00 | 1.00 / 1.00 | 1.00 / 1.00 |

- Спрос B по населению сжимается вчетверо: стартовый спрос B был втрое выше на душу, чем у A.
- B больше не покупает столько металла, металл A дешевеет, а транспорт сжимается вдвое.
- Рынок труда A сбалансирован; в B — избыток рук, и зарплата B идёт вниз. На 3 годах медленно, за десятилетия — до 108 (прототип).
- Во всплеске транспорта предохранитель срабатывает: доступность труда A падает до 0.96.

**80 лет (исследование, не validation):** зарплаты сходятся (104 / 108), занятость в обоих регионах ≈ 0.94. Исчезает парадокс шага 2: люди уезжали из A, хотя там не хватало рук.

**Известные свойства шага:**
- спрос от дохода отложен — без финансового слоя он даёт спираль зарплат;
- предохранитель на транспорте не действует: у транспорта общий для регионов труд;
- безработица около 6 % в равновесии — следствие цели 0.95.
